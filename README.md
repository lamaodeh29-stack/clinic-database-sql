# Clinic Database SQL Project

## Project Overview

This project is a PostgreSQL database for managing a clinic.

The database includes patients, doctors, appointments, medicines, prescriptions, and prescription items.

The project focuses on SQL and database design using PostgreSQL.

## Database Tables

- Patients
- Doctors
- Appointments
- Medicines
- Prescriptions
- Prescription Items

## How to Run

1. Create a PostgreSQL database.
2. Run schema.sql to create the tables.
3. Run data.sql to insert the sample data.
4. Run views.sql to create the views.
5. Run queries.sql to run the analysis queries.
